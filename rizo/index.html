Sobre el nudo

Para qué sirve

Ata las dos puntas de una misma cuerda alrededor de algo, para que quede apretado: un paquete, un bulto, un saco o una venda. Queda plano, así que no molesta, y se desata fácil. Es también el nudo que hay debajo del lazo de los cordones.

Materiales

Una cuerda de 1 m, de 4 a 8 mm, o dos cuerdas del mismo grosor. En las imágenes, cada punta es una cuerda de otro color: la izquierda y la derecha.

Precauciones

  • No lo uses para unir dos cuerdas que van a cargar: si tiras fuerte o la cuerda se sacude, se deforma y se suelta. Para eso usa la vuelta de escota.
  • Si tiras de una punta hacia afuera, el nudo se deshace. Así se desata rápido, pero también se puede soltar si una punta se engancha.
  • Con cuerdas de distinto grosor o resbalosas se corre y no aguanta.

Alternativas

  • Vuelta de escota. Para unir dos cuerdas, sobre todo si van a cargar o si son de distinto grosor.
  • Pescador. Para unir dos cuerdas delgadas o resbalosas, como dos sedales.
  • Nudo de cirujano. Cuando el primer medio nudo se afloja mientras haces el segundo, como al atar un paquete apretado: en el primero das dos vueltas en vez de una.
