Sobre el nudo

Para qué sirve

Sujeta una cuerda a un tronco, un palo o un atado de leña para arrastrarlo o levantarlo. Se hace rápido y, cuando dejas de tirar, se deshace casi solo. Con ella empieza el amarre diagonal.

Materiales

Una cuerda de unos 2 m y un palo grueso o un tronco, de 5 a 10 cm de ancho.

Precauciones

  • Solo aguanta mientras el firme tira. Si la cuerda se afloja, el nudo se suelta: no lo uses para algo que tenga que quedar atado.
  • En un palo liso o con una cuerda resbalosa, el chicote se puede salir. Dale más vueltas.
  • Para arrastrar un tronco largo, pasa además un cote alrededor del tronco, cerca de la punta hacia la que tiras, para que el tronco no se atraviese.

Alternativas

  • Media llave y dos cotes. Cuando la cuerda va a quedar atada mucho tiempo o a ratos se afloja: no se suelta sola y se desata fácil.
  • Constrictor. Cuando quieres que quede apretado aunque nada tire, como para cerrar un atado de leña: no se suelta, pero cuesta desatarlo.
